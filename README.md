# Onglets verticaux

Complément Excel (Mac et Windows) qui affiche les feuilles du classeur dans un panneau latéral vertical.

- Clic : aller sur la feuille
- Double-clic : renommer
- Clic droit : renommer, dupliquer, masquer/afficher, couleur d'onglet
- Glisser-déposer : réordonner
- Champ de recherche, bouton + pour une nouvelle feuille

Astuce : masquer la barre d'onglets native dans Excel > Préférences > Affichage > « Onglets de feuille ».
